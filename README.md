# 🧙‍♂️ Inferus Video Game

¡Bienvenidos al repositorio oficial de **Inferus Video Game**! 
Este es un proyecto de acción y aventura desarrollado en Unity, donde la magia y el combate cuerpo a cuerpo se unen. 

## 🎮 Sobre el Proyecto


## ✨ Características Principales (Hasta ahora)
* **Movimiento Fluido:** Sistema de locomoción completo (Caminar, Correr) utilizando la cámara `Cinemachine FreeLook`.
* **Combate Mixto:** * Ataques básicos de puñetazos.
  * Sistema de Combos encadenados (Hook Punch -> Kicking).
* **Magia y Armas:** Sistema de equipamiento dinámico para sacar y guardar la varita mágica.
* **Animaciones:** Integración y sincronización de animaciones importadas desde Mixamo.

## 🛠️ Tecnologías y Herramientas
* **Motor Gráfico:** Unity 6
* **Lenguaje:** C#
* **Animaciones:** Mixamo
* **Control de Versiones:** Git & GitHub
